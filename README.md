# YJS AI Labs Storefront

Validation-first storefront for the YJS AI Labs product portfolio.

## Live products
- Agent Budget Router Community — open source
- AI Stack Control Plane — founding validation
- Context Optimizer — product moat / planned Pro capability
- MCP / Agent Security Quick Audit — service validation

## Operating principle
Payment approval is not a build dependency. Planned prices are displayed transparently while early-access issue forms collect willingness-to-pay evidence. No payment is taken until the Merchant-of-Record stack is approved and connected.

## Safety
Never post credentials, customer data, private prompts or confidential infrastructure details in public issues.
